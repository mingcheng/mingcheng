I'm mingcheng (明城), an open-source practitioner originally from Ningbo and now based in Hangzhou, China. I enjoy building useful software and supporting the communities behind it.

I'm a senior software architect and open-source evangelist at [Ant Group](https://github.com/antgroup). Previously, I spent nearly a decade at [NetEase](https://www.netease.com/) as a senior technical lead and team manager.

My background is in cloud-native systems and software architecture, with a recent focus on AI agents and infrastructure. I value clean design, reliable automation, and turning ideas into practical, dependable systems.

I've used Linux for many years. [NixOS](https://github.com/mingcheng/nixos-configuration) is my daily driver, and I prefer Debian for servers. I also use macOS for development and testing.

## 🛠️ Personal Projects

In my spare time, I build and maintain small tools for everyday development and terminal use:

- [aigitcommit](https://github.com/mingcheng/aigitcommit) — A Conventional Commit message generator using OpenAI-compatible APIs.
- [mp3blstr](https://github.com/mingcheng/mp3blstr) — A terminal music player inspired by mp3blaster.
- [simplyddns](https://github.com/mingcheng/simplyddns) — A dynamic DNS updater with configurable IP sources and DNS providers.
- [socks5lb](https://github.com/mingcheng/socks5lb) — A SOCKS5 proxy load balancer with automatic health checks.
- [stupidict](https://github.com/mingcheng/stupidict) — An offline English-Chinese dictionary for the terminal.

You can install them from my [Homebrew tap](https://github.com/mingcheng/homebrew-tap) with `brew install mingcheng/tap/<package>`. Browse my [GitHub repositories](https://github.com/mingcheng?tab=repositories) for more projects.
